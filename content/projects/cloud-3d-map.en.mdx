<Problem>

The platform's maps were mostly 2D. Clients wanted the high-fidelity 3D that had become standard in the industry, without needing a powerful GPU on every machine.

</Problem>

<Role>

Lead developer. I built the map features and Blueprint interfaces in Unreal Engine, the web map plugin, and the cloud-rendering configuration console.

</Role>

<Approach>

### Render on the server

I built the 3D map in Unreal Engine and used Pixel Streaming to send the rendered frames to the browser as a video stream. The browser only plays the stream and sends input back, so client machines don't need a powerful GPU.

<Flow caption="Figure 1 · Frames stream from the render server to the browser; mouse input and plugin commands go back to the engine.">

### One map plugin

Blueprints expose the engine's features as interfaces, and a TypeScript/React plugin wraps them so every product page calls the same API:

- Placing and controlling device markers
- Fly-through and orbit cameras
- Exploded floor views
